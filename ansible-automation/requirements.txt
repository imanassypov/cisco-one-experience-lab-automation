# SSH transport for ansible.netcommon.network_cli, which 02_data_center's
# serial discovery uses to reach the NX-OS switches. The plugin's ssh_type
# defaults to `auto`: it imports ansible-pylibssh if present and otherwise
# warns "ansible-pylibssh not installed, falling back to paramiko" and uses
# paramiko. Both work, but netcommon deprecated the paramiko path for removal
# after 2028-02-01, so install the one it wants. PyPI ships manylinux wheels
# with libssh bundled, so this needs no apt package and no compiler - which
# matters on the Kali image, where apt-installing SSH tooling drags libc6
# forward and apt refuses against the pinned libc6-dev.
