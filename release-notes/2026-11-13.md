# 2026-11-13

- **repo — the student guide moved to its own repository.** `docs/` (368 MB of
  HTML, screenshots and sample reports, and about 470 MB of its history) is now
  [cisco-one-experience-lab-guide](https://github.com/imanassypov/cisco-one-experience-lab-guide),
  published at https://imanassypov.github.io/cisco-one-experience-lab-guide/.
  Its git history came with it. Here, `docs/` holds only a redirect, so the old
  Pages URL, including `#section` links, still lands on the guide. Edit the
  guide in its own clone; do not add guide content back to this repository.
- **bootstrap — student clones are shallow.** Every clone command (guide,
  `stage-script-server.sh`, `00_preflight.yml`, the bootstrap and EVPN READMEs)
  is now `git clone --depth 1 --single-branch`. With the guide gone, that pulls
  only the current automation tree instead of every docs revision ever pushed.
  `git pull` works unchanged on a shallow clone. Existing full clones keep
  working, and a `git pull` on one deletes the local `docs/` content.
